CARA PASANG PWA VJS FINANCE
===========================
1. Deploy Apps Script: Deploy > New deployment > Web app
   - Execute as: Me
   - Who has access: Anyone   (WAJIB, agar bisa dimuat di dalam PWA)
   Salin URL berakhiran /exec.
2. Buka index.html di folder ini, ganti APPS_SCRIPT_URL dengan URL tadi.
3. Upload SELURUH isi folder ini ke hosting statis HTTPS gratis, mis.:
   GitHub Pages, Netlify (drag & drop folder), Cloudflare Pages, atau Firebase Hosting.
4. Buka alamat hosting di Chrome > klik ikon "Instal" di address bar
   (atau menu ⋮ > Instal aplikasi / Tambahkan ke layar utama di HP).
